UnipusAI-Helper v3.9.19 — Windows 安装版 / 便携版
==================================================

本版本在 v3.9.9（内置 FFmpeg / WinUI 3 自适应界面）基础上新增：
  * release / debug 两种构建，由 UNIPUS_BUILD_MODE 环境变量切换；
  * release 为纯 GUI 启动，不显示终端窗口（推荐日常使用）；
  * debug 保留控制台窗口输出运行日志，便于排错（exe 名带 -Debug 后缀）；
  * 安装版与便携版分别由独立 GitHub Actions job 打包；
  * 便携 ZIP 使用最高 Deflate 压缩；
  * macOS 同步提供 .dmg 安装包（arm64 / x64 × release / debug）。
  * 安装向导全面中文化，欢迎页显示「欢迎安装 UnipusAI-Helper-NEXT」，
    并采用 WinUI 3 / Fluent 风格（Segoe UI 字体、Mica 浅色背景、蓝色强调
    标题、圆角按钮与自定义向导插图 / 图标）。
  * 内置 Whisper base 模型权重（whisper_models/base.pt，约 145 MB），首次语音
    识别无需联网下载模型；FFmpeg 与 Whisper 均随安装包 / 便携版一起发布。

版本区别
--------
  release  UnipusAI-Helper.exe         无控制台窗口，纯 GUI 启动；
           标准输出 / 标准错误自动写入 logs/gui-stdout.log 与 gui-stderr.log，
           致命错误以系统弹窗提示（可用 UNIPUS_GUI_NO_DIALOG=1 关闭弹窗）。
  debug    UnipusAI-Helper-Debug.exe   保留控制台窗口，日志同时打印在终端；
           适合排查驱动下载失败、QML 加载异常等问题。

安装方式
--------
  1) 安装包（推荐）：双击 UnipusAI-Helper-Setup-3.9.19-win-x64-<mode>.exe，
     默认安装到 %LOCALAPPDATA%\UnipusAI-Helper（用户级，无需管理员权限；
     目录可写，config.json 与 logs/ 就放在程序目录里），并创建开始菜单与可选
     桌面快捷方式；卸载到「设置 → 应用 → 安装的应用」中操作。
  2) 便携版：把 UnipusAI-Helper-3.9.19-win-x64-<mode>.zip 解压到任意可写目录，
     直接双击其中的 exe 即可，无需安装、无需管理员权限。
  <mode> 为 release 或 debug；两种版本使用不同的 AppId，可并存安装。

目录说明
--------
  UnipusAI-Helper.exe（或 -Debug.exe）  主程序（内置「设置」页）
  config.json            运行配置（首次已附带空模板）
  _internal/             运行所需依赖库（请勿删除或改名）
                         其中 _internal/ffmpeg/win32-x64/ 为内置 FFmpeg 二进制
                         其中 _internal/whisper_models/base.pt 为内置 Whisper base 权重
  logs/                  运行日志；release 版的控制台输出也写在这里
  _发布说明_READ_ME_FIRST.txt  本文件

使用步骤
--------
1. 双击 exe 启动。首次启动时 config.json 里没有 API Key，程序会自动打开内置
   「设置」页，不会先启动浏览器，也不会因空密钥报错。
2. 在「设置」页填写 Unipus 账号、密码、API Key / Base URL / 模型等，点「保存设置」。
   窗口会自动关闭，按提示重新启动程序即可生效。
3. 以后随时可以点侧栏「设置」修改配置；保存后重启程序生效。
   如需跳过环境自检，可在命令行运行：UnipusAI-Helper.exe --skip-check
4. 语音识别所需的 FFmpeg 已内置，启动时自动加入 PATH；环境自检会打印
   「使用内置 FFmpeg: ...\ffmpeg\win32-x64」。仅当内置文件被误删时，才会提示
   原有的下载 / 手动指定兜底选项。
   Whisper 的 base 模型权重同样已内置，启动时作为 download_root 传给
   whisper.load_model，首次识别无需联网下载约 145 MB 模型；仅当内置文件缺失时
   才回退到 whisper 默认的联网下载 / 用户缓存。
5. GUI（release）模式下交互式的环境检查菜单会自动跳过，缺项只记录到日志并继续，
   不会因为没有终端输入而卡住；需要逐项排查时改用 debug 版。

运行环境要求
------------
  * Windows 10/11 64 位
  * Microsoft Edge 浏览器（用于 Selenium 自动化）
  * FFmpeg：已内置，无需额外安装
  * Whisper base 模型：已内置，首次识别无需联网下载模型
  * 网络可访问 Unipus 平台与所配置的 AI API
  * 首次启动会由 Selenium Manager 自动匹配并下载与 Edge 版本对应的
    msedgedriver（缓存在 logs/selenium_cache/）；该步骤需要联网。
    若机器无法访问微软驱动下载站点，可手动把对应版本的 msedgedriver.exe
    放到下列路径后再启动（版本需与 Edge 主版本号一致，例如 157）：
      logs/selenium_cache/msedgedriver/win64/<Edge完整版本号>/msedgedriver.exe
    并设置环境变量 SE_OFFLINE=true 让 Selenium Manager 直接使用缓存、
    跳过联网查询。

界面主题（可选）
----------------
  * 默认自动跟随 Windows 的浅色/深色应用模式与系统强调色。
  * 可用环境变量覆盖：
      UNIPUS_THEME=dark|light   强制深色或浅色
      UNIPUS_ACCENT=#RRGGBB    自定义强调色

注意
----
  * config.json、logs/ 均生成在本目录（与 exe 同级），升级时请保留 config.json。
  * 主程序含 PyTorch / Whisper / PySide6 等大型依赖，首次启动稍慢属正常。
  * 旧版独立配置编辑器 config_editor.py 仅保留在项目源码中，不再单独发布。

构建与验证
----------
  * 使用 PyInstaller 6.22.3 / Python 3.12 打包，同一份 UnipusAI-Helper.spec
    由 UNIPUS_BUILD_MODE=debug|release 生成两种版本（console 开关随版本切换）；
    Windows 构建以 SHA-256 校验固定版本的 UPX 后压缩 exe 和兼容 DLL。
  * 安装向导资源位于 installer/：ChineseSimplified.isl（简体中文语言文件，
    UTF-8 BOM）、WizardImage.bmp / WizardSmallImage.bmp（WinUI 3 风格插图）、
    UnipusAI-Helper.ico（安装包图标）；.iss 的 [Code] 段在 InitializeWizard 里
    应用 Fluent 字体 / 配色与圆角按钮。这些文件需纳入版本控制，CI 才会生效。
  * 构建前先准备内置 FFmpeg：
      .venv\Scripts\python.exe scripts/fetch_ffmpeg.py --platform win32-x64
     再准备内置 Whisper 权重（复用本机 ~/.cache/whisper 或从官方镜像下载并校验）：
       .venv\Scripts\python.exe scripts/fetch_whisper.py
    分别构建 payload、便携版和安装版：
      .venv\Scripts\python.exe scripts/build_variant.py --mode release
      .venv\Scripts\python.exe scripts/build_variant.py --mode debug
      .venv\Scripts\python.exe scripts/build_variant.py --mode release --installer-only --package-target portable
      .venv\Scripts\python.exe scripts/build_variant.py --mode release --installer-only --package-target installer
    冒烟测试：.venv\Scripts\python.exe scripts/smoke_test.py --mode release
  * 已验证：两种版本均可 offscreen 启动、QML 设置页正常加载、release 无终端且
    标准输出重定向到日志、内置 FFmpeg 命中 PATH、内置 Whisper base.pt 随
    payload 发布且离线 load_model 直命中本地文件、安装包与便携 zip 结构完整。
  * Windows 便携 ZIP 使用 Deflate level 9；安装包使用 Inno Setup LZMA2 固实压缩。
    两类产物由独立 GitHub Actions job 构建并分别发布，避免安装版与便携版耦合。
  * GitHub Actions：.github/workflows/build-windows.yml 分开执行 payload、便携版和安装版 jobs；
    打 v* 标签时发布到 GitHub Release，也可手动选择发布，无需配置代码签名证书。
  * 本机若出现 Selenium Manager 联网失败（无法获取 msedgedriver），
    属于运行环境网络问题，不是 exe 打包问题；按上节使用缓存驱动即可。

macOS 版本
----------
  macOS 版由 .github/workflows/build-macos.yml 在 macos-15（arm64）与
  macos-15-intel（x64）上按 release/debug 构建四个 .dmg：release 为可直接拖入
  「应用程序」的 .app（无终端），debug 为文件夹 + Run-Debug.command（终端启动）。
  配置与日志位于 ~/Library/Application Support/UnipusAI-Helper/，
  详见 README.md 的「macOS」一节。
